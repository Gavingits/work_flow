# Visual Workflow Editor

这是一个使用 Python 和 PyQt5 构建的可视化工作流编辑器。它允许用户通过图形化界面，将不同的“工具”（即独立的Python模块）连接成一个节点网络，以定义和执行自动化的数据处理流程。

## 主要功能

- **可视化编辑**: 提供一个画布，用户可以从工具列表中拖拽工具来创建节点，并用鼠标在节点之间创建连接线。
- **动态工具发现**: 自动扫描 `tools` 目录，发现可用的工具并显示在列表中。
- **节点配置**: 支持双击节点，打开由工具自身提供的、独一无二的配置界面。
- **保存与加载**: 可以将整个工作流（包括所有节点、位置、连接和每个节点的具体配置）保存为 `.json` 文件，并能随时加载恢复。
- **工作流执行引擎**:
  - 能够根据节点连接关系，通过拓扑排序智能地计算出正确的执行顺序。
  - 能够检测并阻止因循环连接而导致的执行错误。
  - 能够真正调用每个工具的 `run` 函数，并通过在临时目录中管理文件，来处理节点之间的数据传递。

## 快速上手指南

### 1. 运行程序

确保您已安装所有依赖项后，在项目根目录运行：

```bash
python3 main.py
```

### 2. **【重要】** 设置工作流目录

程序启动后，您会看到一个空白的界面，左侧的工具列表是空的。这是正常现象。

**为了加载工具并开始使用，您必须先指定工作流目录：**

1.  点击顶部菜单栏的 **“文件” (File)**。
2.  选择 **“设置工作流目录...” (Set Workflow Directory...)**。
3.  在弹出的对话框中，选择**本项目的根目录**（即包含 `main.py` 和 `tools` 文件夹的那个目录）。

选择正确后，左侧的工具列表会自动刷新，并显示出 `tools` 文件夹中所有可用的工具（例如 `doe_generator`）。

### 3.搭建工作流

- **创建节点**: 从左侧工具列表中，用鼠标将一个工具拖拽到右侧的画布上。
- **连接节点**: 点击一个节点的输出端口（右侧圆点），按住鼠标拖拽到另一个节点的输入端口（左侧圆点），然后松开鼠标。
- **配置节点**: 双击任意一个节点，会弹出该节点的配置窗口。

### 4. 保存、加载与执行

- **保存**: 点击菜单栏“文件” -> “保存工作流...”，可以将您当前的设计保存为 `.json` 文件。
- **加载**: 点击菜单栏“文件” -> “加载工作流...”，可以选择一个之前保存的 `.json` 文件来恢复您的工作。
- **执行**: 点击菜单栏“工作流” -> “运行”，程序将按照您设计的流程，从起始节点开始，依次执行所有工具。执行日志和结果会打印在启动程序的控制台（命令行）中。

## 如何添加新工具

本框架被设计为易于扩展。要添加一个新工具，您只需：

1.  在 `tools` 文件夹中创建一个新的 Python 文件（例如 `my_new_tool.py`）。
2.  在该文件中，至少定义一个 `run` 函数，其签名必须为：
    ```python
    def run(input_path, output_path, config_data):
        # ... 你的处理逻辑 ...
        # 从 input_path 读取数据
        # 将结果写入 output_path
        # config_data 是一个包含此节点配置的字典
    ```
3.  （可选）如果您希望您的工具可以被配置，再定义一个 `get_config_widget` 函数。该函数需要返回一个 `QWidget` 的实例。这个 `QWidget` 需要实现两个方法：
    - `load_config(data)`: 从一个字典加载UI状态。
    - `get_config()`: 返回一个包含当前UI状态的字典。

完成以上步骤后，重新启动主程序并设置正确的工作流目录，您的新工具就会自动出现在工具列表中。
